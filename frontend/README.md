# Frontend

Interfaz web desarrollada con HTML, CSS y JavaScript. El punto de entrada es `index.html`.

Para servirla en desarrollo con Python, desde esta carpeta ejecutar:

```powershell
py -m http.server 8081
```

Luego abrir `http://localhost:8081`. Si `py` no esta disponible, usar `python -m http.server 8081`. El backend debe estar activo en `http://localhost:3000`.
