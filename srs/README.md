# Especificacion de requerimientos

La especificacion funcional vigente se encuentra en la seccion [Requerimientos funcionales](../README.md#requerimientos-funcionales) del README principal.

Los requerimientos distinguen entre rutas propuestas y funcionalidades implementadas. El RF11, gestion de clases, permanece pendiente de definicion: falta acordar operaciones, actores y relacion con calendario, horarios y asistencias.
