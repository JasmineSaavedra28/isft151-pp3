# Pruebas

Esta carpeta reunira casos de prueba, pruebas automatizadas y evidencias vinculadas con los requerimientos funcionales.

Actualmente no hay una suite ejecutable en el repositorio. El comando `npm test` del backend falla porque intenta cargar `backend/run`, archivo que no existe. Al incorporar pruebas, actualizar el script de `backend/package.json` y documentar aqui como ejecutarlas.
